# Dataset policy

Datasets are not committed to GitHub. Use only synthetic, public, or explicitly consented material—never real identity documents, passports, visa pages, biometric data, or personal information.

Potential future sources (after licence and privacy review):

- Synthetic documents generated specifically for demonstrations.
- Public computer-vision benchmark images that permit educational/research use.
- Public document-layout/OCR datasets with non-sensitive samples and compatible licences.

Record each dataset's source, licence, consent basis, intended use, and preprocessing steps in project documentation before use.
