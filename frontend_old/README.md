# Frontend

This is a minimal React + Vite + Tailwind CSS scaffold. The dashboard is intentionally deferred until the UI implementation phase.

## Run locally

```powershell
cd frontend
npm install
npm run dev
```

Vite prints the local URL, normally `http://localhost:5173`. Start the backend
on `http://127.0.0.1:8000` first. The page provides a real file upload,
preview, upload status, validation/network errors, and returned image metadata.
